# 新账号额度阈值与分组批量并发

版本：`0.2.19-yoshub.account-controls.1`，基于官方 v0.2.19。

新建或导入 OpenAI 账号时，未指定的 5 小时和 7 天额度阈值均写为 99%。账号新增的统一持久化入口补齐默认值，因此 JSON、Codex、OAuth、批量创建等入口一致。导入文件已明确指定的阈值及禁用设置予以保留。现有账号及其后续编辑不自动补值。

阈值作用于上游已用额度百分比。任一窗口达到阈值后，已有配额调度逻辑停止分配新请求；窗口重置后恢复。在途请求和上游用量刷新存在延迟，不能保证最终用量精确停在 99%。

账号管理上方新增“批量调整并发”。先选择分组，打开弹窗确认匹配总数，输入正整数并应用。操作沿用当前平台、类型、状态、搜索及隐私筛选条件，覆盖所有分页；未分配分组也可单独选择。更改的是账号本身的并发上限，同一账号被其他分组引用时也使用该值。

原有调度继续按较小优先级数字优先。批量并发请求仅提交筛选条件和并发数，不改变账号优先级、分组绑定或凭据。

验证：相关后端单元测试、临时 PostgreSQL 数据库的新增/更新集成测试、84 项相关前端测试、TypeScript 检查与修改文件 ESLint 检查通过。浏览器使用本地模拟接口验证了分组限制、501 条跨分页范围、并发 37 的请求载荷及响应后的页面刷新；不向生产账号提交验证修改。
